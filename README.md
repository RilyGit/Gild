GildApp

Full-stack веб-приложение для управления личными финансами, учета доходов и расходов. Проект разработан с акцентом на чистую архитектуру, безопасность данных и изоляцию пользовательских сессий.

Стек технологий

- Frontend: React, Vite, CSS
- Backend: Node.js, Express
- Безопасность: JSON Web Token (JWT), bcrypt (хеширование паролей), защищенные middleware-маршруты
- Хранение данных: localStorage

Основной функционал

- Регистрация и авторизация с валидацией полей (проверка email и длины пароля от 8 символов).
- Изоляция данных: каждый пользователь имеет доступ только к собственным транзакциям и балансу.
- Добавление доходов и расходов с привязкой к категориям и динамическим пересчетом баланса.
- Корректная обработка истечения срока сессии (автоматический выход при 401 Unauthorized).

Быстрый старт (Локальная установка)

Убедитесь, что на вашем компьютере установлена Node.js (LTS).

1. Клонирование репозитория
git clone https://github.com/RilyGit/Gild.git
cd Gild

2. Запуск бэкенда
cd server
npm install
node app.js
(Сервер запустится на порту 3100)

3. Запуск фронтенда
В новом окне терминала:
cd client
npm install
npm run dev
(Клиент будет доступен по адресу, указанному в терминале, обычно http://localhost:5173)

Адрес API настраивается через переменную Vite `VITE_API_URL`. Если переменная не задана,
клиент использует рабочий бэкенд `https://gild-tdos.onrender.com`. Для локальной настройки
скопируйте `client/.env.example` в `client/.env` и измените значение при необходимости.

Структура проекта

- client/ — клиентская часть на React и Vite.
- server/ — серверная часть на Node.js и Express.
